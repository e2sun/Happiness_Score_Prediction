# 😊 Lab 8 – Happiness Score Prediction

This repository contains the work for **Lab 8**, which focuses on defining and solving a machine learning problem to predict a country's Happiness Score using global indicators from the World Happiness Report dataset.

The project follows the complete ML pipeline — from data cleaning and feature engineering to training and evaluating a regression model — with comparisons between Linear Regression and Random Forest.

---

## 🧠 Topics Covered

- Data cleaning and preprocessing  
- Handling missing values and outliers  
- Feature selection using correlation and RFE  
- Regression modeling with scikit-learn  
- Model evaluation (MAE, RMSE, R²)  
- Model comparison (Linear vs. Random Forest)  
- Data visualization with Matplotlib and Seaborn  

---

## 📁 Files

- `HappinessScore.ipynb` — Main notebook for Lab 8 (EDA, modeling, and evaluation)  
- `HappinessScore.py` — Script version of the notebook for reproducibility  
- `WHR2018Chapter2OnlineData.csv` - Dataset loaded from World Happiness Report 
---

## ✅ Key Insights

- Random Forest significantly outperforms Linear Regression on this dataset  
- Key drivers of happiness include GDP per capita, social support, and healthy life expectancy  
- Strong generalization achieved through feature filtering and model tuning
